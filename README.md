# 🛍️ Customer Segmentation System

A Machine Learning project built using K-Means Clustering and Streamlit.

## Features
- Customer Segmentation
- K-Means Clustering
- Interactive Web App
- Machine Learning Deployment

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
